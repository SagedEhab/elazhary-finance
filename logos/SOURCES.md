# Logo sources

Downloaded 2026-11-04 from Wikimedia Commons and cropped to each bank's symbol.
Commons lists these files as public domain, but the logos are still the banks'
trademarks. They're here to identify the owner's own banks in a personal app.

- `nbe.png`: https://commons.wikimedia.org/wiki/File:National_Bank_of_Egypt.svg
- `misr.png`: https://commons.wikimedia.org/wiki/File:Banque_Misr.svg
- `cairo.png`: https://commons.wikimedia.org/wiki/File:Banque_du_caire_Logo.svg
- `cib.png`: https://commons.wikimedia.org/wiki/File:Cib_Logo.svg
- `fab.png`: https://commons.wikimedia.org/wiki/File:First_Abu_Dhabi_Bank_Logo.svg
- `abc.png`: https://commons.wikimedia.org/wiki/File:BankABCLogo.svg
